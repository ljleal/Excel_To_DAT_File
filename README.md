BIR Alphalist Excel to DAT Converter

Overview
This application helps users prepare data for the BIR Alphalist Data Entry Application without manually entering records one by one.

Users only need to complete the provided Excel template, upload it to the application, and the system will generate a DAT file that can be imported into the BIR Alphalist application.

Purpose
The purpose of this tool is to make Alphalist data preparation:
- Faster
- Easier
- Less prone to encoding errors

This eliminates the need for manual, record-by-record data entry.

How to Use
1. Download the provided Excel template.
2. Fill out the Excel file according to the required format.
3. Upload the completed Excel file to the application.
4. The application will generate a DAT file.
5. Import the generated DAT file into the BIR Alphalist Data Entry Application.

Input and Output
Input:  Excel file (.xlsx) using the prescribed format
Output: DAT file ready for import into the BIR Alphalist application

Important Notes
- Make sure the Excel file strictly follows the provided format.
- Incorrect or missing data may cause errors during import.
- This tool is intended only to assist in data preparation and does not replace the official BIR application.
